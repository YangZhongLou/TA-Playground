# 问题空间与三层模型

图生体素不是单一算法。先把问题拆开，再选表示、生成方式和引擎消费路径。

## 要回答的四件事

| 问题 | 选错时的症状 |
| --- | --- |
| 格子里存什么 | 只要占用却做成了体积雾；只要外观却丢掉了可破坏实心 |
| 分辨率谁说了算 | 32³ 能玩方块风格，1024³ 才能当神经几何潜空间 |
| 空格子怎么处理 | 密集体素显存爆掉；稀疏结构写着色器变复杂 |
| UE 里谁来画 | 把 Nanite 简化、SVT、方块网格、地形插件叫成同一个「体素」 |

玩家感知的「方块感」来自消费层着色与碰撞，不来自生成模型的论文名。
程序化 CSG 直接写占用。TRELLIS 一类模型内部是稀疏体素，导出仍可是网格或高斯。本目录不调用 Hunyuan。

## 三层模型

每一层独立选择。口头上说「我们做体素」，要写清三层各是哪一种。

### 1. 表示：格子里是什么

| 表示 | 每格内容 | 擅长 |
| --- | --- | --- |
| 二值占用 | 空 / 实 | 碰撞、破坏、Minecraft 式编辑 |
| 调色板占用 | 占用 + 颜色索引 | 体素画、MagicaVoxel |
| SDF / 占用场 | 连续标量 | 平滑表面、行进立方体、可雕刻地形 |
| 多属性体积 | 密度、温度、速度 | 烟火，半透明介质 |
| 结构化潜变量 | 表面体素 + 特征向量 | 神经生成，再解码成网格 / 高斯 / 辐射场 |

表示决定能做什么玩法。调色板占用做不出半透明火焰；SVT 密度场做不出稳的方块碰撞。
细则见 [representations.md](representations.md)。

### 2. 生成：图怎么变成格子

| 生成 | 输入 | 前提 |
| --- | --- | --- |
| 像素挤出 | 精灵图 / 像素画 | 物体接近 2.5D，厚度人工给 |
| 高度图柱体 | 灰度或彩色俯视图 | 无悬空、无孔洞 |
| 程序化 CSG | 规则几何 | Grok 写球 / 柱 / 盒 |
| 剪影雕刻 | 多视角剪影 | 凹形会填实，需要多视角 |
| 网格体素化 | 已有 mesh | 自备 DCC 网格 |
| 神经稀疏体素 | 单图或文 | 未接入；输出常再 meshing |

经典方法 CPU 可复现，本目录脚本覆盖挤出、高度图和 Grok CSG。
神经方法本目录不接入。细则见 [pipelines.md](pipelines.md)。

### 3. 消费：引擎怎么用这份格子

| 消费 | 引擎对象 | 适用 |
| --- | --- | --- |
| 合并方块网格 | Static Mesh / ISM | 道具、建筑块、调色板风格 |
| 稀疏体积纹理 | SVT + Heterogeneous Volume | 烟、火、尘，OpenVDB 来源 |
| Nanite 体素化 | 网格构建设置 | 远处几何简化，不可编辑 |
| SDF 地形插件 | Voxel Plugin 2 | 可挖可塑的地形，不是立方体世界 |

四条路径的数据布局和材质域都不同，不要共用一套导入器。见 [unreal.md](unreal.md)。

## 图生网格 vs 图生体素

图生 3D 的工业默认终点是**带 UV 的三角网格 + PBR**。体素是另一条终点，或同一条管线里被丢掉的中间层。

| | 图生网格 | 图生体素 |
| --- | --- | --- |
| 默认产物 | `.glb` / Static Mesh | `.vox` / 占用场 / VDB |
| 表面 | 连续，依赖法线与贴图 | 离散，依赖格子分辨率 |
| 编辑 | 进 DCC 或 Nanite | 逐格挖填，破坏便宜 |
| 拓扑 | 要流形、要 UV | 天然支持孔洞与非流形内部 |
| 本目录 | 不调用 | 挤出 / CSG / 可选网格采样 |

不要把图生网格接到本目录上。像素画挤出，预制件走 Grok CSG。已有 DCC 网格才体素化。

## 和 Hexagon 的关系

[Hexagon](../Plugins/Hexagon/Documents/DESIGN.md) 是六边形格子上的 **2.5D 占用**：每个 cell 一根柱体，高度变化，没有真正的三维悬空。
体素是立方格子上的 **3D 占用**：可以挖洞、做桥、做内部空腔。

离散几何这件事两边是亲戚。晶格、维度、消费路径不同，不要把 hex terrain 改造成体素引擎。

## 本仓库的默认切分

| 资产类型 | 走哪层 |
| --- | --- |
| 需要 PBR 与平滑轮廓的道具 | DCC 网格，不进本目录 |
| 像素画风道具、破坏碎块 | 调色板占用 → `.vox` → 合并网格或 ISM |
| 规则预制件 | Grok CSG → `.vox` |
| Niagara 流体缓存 | VDB → SVT，与图生实心无关 |
| 六边形战场 | Hexagon，不进本目录 |

没有全局最优。先定玩法要「可挖的实心」还是「好看的表面」，再选表示。
