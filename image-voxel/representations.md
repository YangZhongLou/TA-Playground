# 体素表示

生成模型可以换，格子语义不能含糊。先定每格存什么，再谈分辨率和稀疏。

## 规则格子

体素把连续空间切成边长为 `s` 的立方体。格子 `(i, j, k)` 对应世界盒
`[i s, (i+1) s) × [j s, (j+1) s) × [k s, (k+1) s)`。

约定先写清，否则 MagicaVoxel、科研 Occupancy、UE SVT 会对不上轴。

| 约定 | 常见选择 | 本目录 CPU 原型 |
| --- | --- | --- |
| 轴 | MagicaVoxel：X 右、Y 深、Z 上 | 同左，导出 `.vox` |
| 原点 | 包围盒一角，或物体中心 | 包围盒最小角 |
| 空值 | 索引 0、占用 0、SDF 大正数 | 不写入 `.vox` |
| 分辨率 | 边长体素数，不是米 | `--max-size` 限制最长边 |

分辨率按边长立方增长。32³ = 32768 格，可全量存在内存里。
256³ = 1677 万格，密集体素已经不适合当可编辑世界；要稀疏或只存表面。

## 每格存什么

### 二值占用

一比特：空或实。碰撞、寻路、布尔运算都便宜。没有颜色，渲染要另附材质或根据邻居估法线。

### 调色板占用

占用 + `uint8` 颜色索引，外加一张 ≤256 色的 RGBA 调色板。这是 MagicaVoxel `.vox` 的核心。
适合手绘体素和像素挤出。不适合照片级纹理；颜色被量化。

### 多通道体素

每格 float 密度、颜色 RGB、材质 ID、损坏值。破坏和上色可以原地改格子。
内存随通道线性涨，通常只在物体级或 chunk 级使用。

### SDF / TSDF

每格存到表面的有符号距离（截断后为 TSDF）。零等值面用行进立方体或对偶轮廓抽出网格。
擅长平滑地形和布尔运算。Voxel Plugin 2 的世界数据是这条亲戚，不是 Minecraft 方块。

### 体积属性（VDB / SVT）

格子是介质采样点：密度、温度、速度。渲染走体积积分，不是光栅化六个方块面。
OpenVDB 用树状稀疏结构存大范围近空的场。UE 把它烘焙成 SVT。见 [unreal.md](unreal.md)。

### 表面稀疏 + 特征向量（SLAT）

[TRELLIS](https://microsoft.github.io/TRELLIS/) 的 Structured LATent：在大约 64³ 的网格上，只激活与表面相交的体素，
每格贴一个由多视角 DINOv2 特征压出来的向量。粗结构来自占用，细节来自特征。
解码器可以分别吐高斯、辐射场、网格。体素在这里是**潜空间的锚点**，不是最终方块。

### 无场稀疏体素（O-Voxel）

[TRELLIS.2](https://huggingface.co/microsoft/TRELLIS.2-4B) 用 O-Voxel 同时编码几何和 PBR 外观，不依赖 SDF 等值面。
号称能表示开放面、非流形和封闭内部。生成分辨率可到 512³–1536³，再经稀疏 VAE 压到少量 token。
导出给游戏时通常仍 meshing 成 GLB。对本仓库，它是「高质量图生」的体素潜空间，不是编辑器方块格式。

## 稠密 vs 稀疏

| | 稠密三维数组 | 稀疏（哈希 / 八叉树 / VDB / 表面列表） |
| --- | --- | --- |
| 索引 | `O(1)` | 多一次间接 |
| 内存 | `O(N³)` | 正比于非空或近表面格 |
| 适合 | ≤64³ 物体、调试 | 高分辨率、场景级、体积特效 |
| 邻域 | 简单 | 要处理 chunk 边界 |

八叉树 / VDB 的分辨率是稀疏占用或 SDF 的格子密度，不是三角数。
调密会让抽出的表面更细，也会让内存按非空格涨。

## 表面体素 vs 实心体素

| | 表面 | 实心 |
| --- | --- | --- |
| 存储 | 壳层，约 `O(N²)` | 体积，最坏 `O(N³)` |
| 破坏 | 挖开会露出空洞，要填或即时外壳化 | 挖开露出内格，物理直观 |
| 神经生成 | SLAT 走表面 | Minecraft / `.vox` 走实心 |
| 网格提取 | 对偶轮廓、FlexiCubes | 方块面合并，或先转 SDF |

图生体素若目标是 MagicaVoxel 画风，用实心 + 调色板。
若目标是神经生成的中间层，用表面稀疏 + 特征或 SDF。本目录第一阶段只做实心调色板。

## 颜色放哪

| 策略 | 做法 | 代价 |
| --- | --- | --- |
| 调色板 | 每格一个索引 | 风格化，256 色上限 |
| 每格 RGB | 实心顶点色或 ISM 自定义数据 | 照片挤出能用，网格合并要拆材质或用顶点色 |
| 贴在抽出的网格上 | 体素只负责形，纹理另生成 | 回到图生网格路线 |
| PBR 存在 O-Voxel 里 | 和几何一起生成 | 推理重，导出仍要烘焙贴图 |

本目录 CPU 原型走调色板：从输入像素量化颜色，写入 `.vox` 的 `RGBA` chunk。
