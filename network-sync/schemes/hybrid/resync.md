# 停拍拉齐结合

锁步 checksum 对不上，没有「下一包纠正坐标」。
收场三选一：踢分叉者、整局作废、发一份权威快照把所有人拉齐。
本包只做第三项。王者主要靠录像和回归，不靠协议自愈。

第一版是**停拍对齐**，不恢复 15Hz。拉齐用**当前服务器世界**，不是 75 拍检查点。
客户端必须**强制回跳**，即使已经跑在快照前面。不要复用只向前的 `ApplyJoin`。

不要并进乐观 `Tick`，也不要把停拍拉齐和重连合成一个「有时跳世界」的杂类。
周期 Join 仍只服务晚到的人。

规格：[../../impl/hybrid/resync.md](../../impl/hybrid/resync.md)。
代码：`NsLockstepResync.*`。泵在 `bDesync` 时不调用 `Tick`。禁止改 `NsLockstep.cpp` 的打拍循环。

| 平时 | 分叉后 |
| --- | --- |
| `X` ← `F` | 停拍；广播当前 `World`；两端强制跳到该世界；不再推进 |

不要每秒预防性全量快照。32 个泵周期对不齐就作废，不要无限 Join。

失败：客户端不理包、服务器还在打拍 → 误用了 `ApplyJoin` 或 75 拍旧快照。
