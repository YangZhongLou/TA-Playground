# 三款对照：守望先锋、Dota 2、王者荣耀

先读这一页建立地图，再进三篇单作：
[overwatch.md](overwatch.md)、[dota2.md](dota2.md)、[honor-of-kings.md](honor-of-kings.md)。

三款都是「一局十人上下、技能很多」。同步方案却不是同一种。
差别来自：**你怎么操作角色、世界在哪台机器算、手机还是 PC、迷雾算不算公平**。
不是来自标签「这是 MOBA」或「这是射击」。

## 三个词必须分开

| 词 | 含义 | 这三款里谁在用 |
| --- | --- | --- |
| 状态同步 | 网上走「现在世界长什么样」（位置、血量、技能态） | 守望先锋、Dota 2 |
| 帧同步 | 网上走「这一拍谁按了什么」，各端自己算出世界 | 王者荣耀（Dota 1 也是，Dota 2 不是） |
| 预测 | 本地先按你的输入演戏，等服务器（或真输入）来纠正 | 守望先锋大量用；Dota 2 基本不用；王者试过又放弃 |

「回滚」这个词在守望先锋和格斗里不是同一件事。
守望先锋：只把**你自己的英雄**倒回服务器快照再演。
格斗 GGPO：把**整局**倒回，换上对端真实输入再演。真值来源不同。

## 同一瞬间，三款各在做什么

设想你按下「进攻键」。不必是同一键位，意思是「我要出手」。

### 守望先锋：本地先打，服务器再判

1. 你立刻看到开火。火箭或子弹在本地生成。
2. 输入（带滑动窗口）飞向专用服务器。
3. 服务器在权威世界里算命中；必要时把世界倒带到你当时的画面。
4. 增量回来。对得上就继续；对不上就只改你自己的英雄。
5. 别人看到的你，是服务器已经确认过的你，不是你机器上的预测。

网上主要走：**你的输入 + 世界状态差**。伤害裁判是服务器。

### Dota 2：先下命令，再等快照画出来

1. 右键或技能键变成一条命令，发给服务器。本地英雄不必先瞬移到未来。
2. 服务器让单位在权威世界里走、放技能、扣血。
3. 大约每 50ms 打一份单位快照下来。
4. 客户端在快照之间插值。即便 ping 为 0，也要几十毫秒才看起来「迈出第一步」。
5. 别人和你看的是同一份服务器世界的不同延迟拷贝，没有「十份独立模拟」。

网上主要走：**单位状态**。伤害裁判是服务器。你自己也不开 FPS 那种预测。

### 王者荣耀：等这一拍输入帧，十台一起算

1. 点技能先变成输入，送到 PvP 服务器。逻辑层此时还没结算这一下。
2. 服务器每 66ms 打一拍，把这一拍的输入（有人缺就空着）广播给十台。
3. 十台用同一套定点逻辑执行这一拍：命中、伤害、位移都在这里算。
4. 表现层插值，所以画面可以 60fps，结算仍是 15Hz。
5. 别人的英雄不是「服务器发来的坐标」，是你这台手机算出来的。

网上主要走：**输入帧**。伤害裁判是每一台客户端的逻辑层（必须算成一样）。

## 一张表对着看

| 问题 | 守望先锋 | Dota 2 | 王者荣耀 |
| --- | --- | --- | --- |
| 网上主要传什么 | 状态增量 + 输入 | 单位快照 | 输入帧 |
| 谁算伤害 | 服务器 | 服务器 | 每个客户端逻辑层 |
| 节拍 | 模拟 60Hz | 快照约 20Hz（Zoid 时期） | 逻辑 15Hz（66ms） |
| 按下后自己何时动 | 立刻（预测） | 等命令到达 + 快照穿过插值窗 | 等输入帧回来，表现再插值 |
| 别人从哪来 | 复制服务器 | 插值服务器快照 | 本地按同一输入算出来 |
| 准星 / 命中扫描 | 要，且做回绕，高 RTT 关掉 | 不要 | 不要 |
| 迷雾 | 可不发看不见的 | 可不发雾外单位 | 本地有全图，界面藏 |
| 掉线重连 | 吃服务器当前状态 | 吃快照，快 | 从开局快进输入，慢 |
| 录像体积逻辑 | 要录状态或演示 | 状态 / 演示 | 输入很小（约 3MB / 20 分钟） |
| 弱网手段 | 输入窗口 + 时间膨胀 | 插值跨过丢包 | 帧冗余 + 到了就演 |
| 改客户端能不能改结算 | 不能 | 不能 | 不能改别人的 Hash 对局，但能看见不该看的 |
| 为何选它 | 枪感和反作弊 | 已有 Source；命令式够用 | 流量、工期、单位多 |

## 为何 Dota 2 和王者玩法像、方案不像

都是点地板、放技能、5v5 推塔。分道的是约束。

**手机流量和发热。** 王者 2015 年面对的是移动网。每秒 15 个输入包，比 100 个单位的状态便宜，录像也小。
Dota 2 是端游，20Hz 单位快照负担得起。

**技能怎么写得完。** 王者当时大约三四个月，还要从 UE 换到 Unity。
C/S 下一个技能要对齐两端表现和判定，端游要两三周。帧同步只写一套逻辑。
Valve 手里已经有 Source 复制，不必为 MOBA 再造确定性。

**操作允许多「肉」。** 两款都不是格斗。王者仍拒绝「先攒几拍再演」，因为动作英雄会钝，
改成到帧就演、表现插值。Dota 2 接受命令延迟加插值，因为英雄本来就要转身起步，不是 WASD。

**迷雾是不是公平的一部分。** Dota 的雾是信息权，状态同步可以不发坐标。
王者逻辑在手机里，雾挡不住改内存。产品能接受外挂对抗，就可以锁步；
把视野当核心规则，就该状态同步。

**重连和赛事。** Dota 2 要观战、秒回、暂停，快照直接支持。
王者必须快进整局输入。能做，但结构更重。

## 为何守望先锋两套 MOBA 方案都不能直接搬

**不能搬王者。** 射击要准星。每 66ms 才承认一次开火，枪会变成排队。
12 人抛体和可破坏场景，各端自算且没有服务器真值，作弊和争议都会爆。
Ford 的前提是：客户端不可当裁判。

**不能搬 Dota 那种「自己也不预测」。**
Dota 点一下，滞后可以藏进转身。守望先锋在扫射、跳、取消技能。
不预测会感到枪在棉花里。同是状态同步，预测旋钮可以拧到两端：
Dota 2 几乎关死，守望先锋默认开到火箭。

## 常见误读

| 听到的话 | 实际情况 |
| --- | --- |
| MOBA 一定是帧同步 | 王者是。Dota 2、英雄联盟是状态同步 |
| 守望先锋讲了 rollback，所以是格斗网码 | 只回退自己的英雄，真值在服务器 |
| 孙勋说 dota 是帧同步，所以 Dota 2 也是 | 他指 Dota 1（War3 地图） |
| 王者逻辑 15 帧，所以画面 15 帧 | 结算 15Hz，渲染可以 60；表现在插值 |
| 帧同步服务器很闲，所以不校验 | 闲的是不广播小兵坐标。Hash、补发、反外挂仍在做 |
| Source 里有 Predictable 字段，所以 Dota 2 在预测走路 | 字段属于引擎；玩法选择是命令 + 插值 |

## 选型时对着三款问

1. 玩家是瞄准，还是点地板，还是帧级对打？瞄准走守望先锋方向。
2. 世界能不能全部放进每台客户端？不能（雾、反作弊、规模）走 Dota 2 方向。
3. 单位是否多到状态发不起，且平台是手机、技能要快写？走王者方向。
4. 先画操作模型和作弊模型，再选「传输入还是传状态」。不要先选品类名。
